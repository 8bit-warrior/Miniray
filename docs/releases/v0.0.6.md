## Miniray v0.0.6 更新说明

- **面板更新界面**：移除原“开发通道”开关，改为“正式版本”和“Actions 构建版本”两个可展开的更新区域。
- **构建历史选择**：读取 GitHub Actions 已成功完成的 Linux 构建，按照创建时间从新到旧排列，显示提交版本、运行编号、构建时间和提交说明。
- **指定构建安装**：支持在面板直接选择并安装历史 Actions 构建，仅展示当前服务器架构可用且未过期的产物。
- **构建验证**：安装前校验所选 Actions 运行记录、提交身份与 GitHub 提供的 SHA-256 产物摘要，阻止不匹配或无效的构建。
- **版本身份与正式版回退**：Actions 构建显示 `dev+提交号`，安装正式 Release 后恢复正式版本号，不再依赖持久的开发通道状态。
- **升级兼容**：继续保留已有数据库、面板配置和独立 Xray 核心，支持 Linux AMD64 与 ARM64。
- **接口与多语言**：新增 Actions 构建列表及按运行编号更新接口，同步更新 13 种语言的界面文案和回归测试。
- **构建修复**：修正 Actions 构建元数据的 Go 格式错误，统一本地、后端检查与打包流程使用的 lint 命令和版本。
- **更新测试修复**：用无效 Actions 构建编号测试替换失效的开发通道测试，明确验证错误原因，避免测试进入真实更新流程。
- **测试清理**：修复负载均衡弹窗测试遗留延迟回调造成的间歇性构建失败。
- **网络测试**：为 AmneziaWG 网络测试动态分配 TCP/UDP 端口，消除固定端口占用导致的间歇性失败。
