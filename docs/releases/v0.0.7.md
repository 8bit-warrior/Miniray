## Miniray v0.0.7 更新说明

- **首次安装安全配置**：全新安装时自动生成高位 Web 端口、8–10 位随机 Web Path、8–10 位随机用户名及 10–12 位随机密码，并直接输出连接信息；不再要求执行单独的初始密码命令。
- **首次安装可选自定义**：生成默认配置后可选择依次自定义端口、Web Path、用户名和密码，应用后自动调用“查看 Web 面板信息”。已有数据库和账号在更新时保持不变。
- **面板导航与布局**：整理菜单结构，将 DNS 和负载均衡归入高级配置，调整 Xray 配置页面与登录页品牌显示，移除已废弃功能的搜索入口。
- **精简遗留功能**：清除 Telegram、Discord、邮件通知及 MTProto 相关的前后端功能、配置、测试与构建残留，并移除不再使用的命令搜索面板。
- **语言策略**：面板界面保留简体中文和英语，根据浏览器语言自动选择；各类 zh 语言标识均使用简体中文。
- **版本更新体验**：改进正式版本与 Actions 构建版本的独立检测及展示，保留构建提交标识，修复最新正式版显示，并增加下载进度与安装中状态。
- **运行与数据维护**：清理退役模块、降低面板内存开销；修复 SQLite 数据库备份恢复过程中 WAL/SHM 文件的处理。
- **发布平台**：正式安装包只包含 Linux amd64 和 Linux ARM64 的 `tar.gz` 文件及 SHA-256 校验清单，不再生成 Windows 安装包。
