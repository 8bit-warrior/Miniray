## Miniray v0.0.3 更新说明

- **终端管理菜单**：顶部展示当前安装的 Miniray 版本号，同时保留面板和 Xray 核心的实时状态及开机自启信息。
- **Web 管理界面**：桌面侧边栏和移动端菜单的顶部展示当前版本号，方便直接确认安装版本。
- **发布说明**：GitHub Releases 改为使用独立的中文版本说明文件，逐条列出改动，不再采用硬编码英文说明。
- **仓库文档**：更新 README 中的版本安装示例、界面介绍和版本发布流程。
- **发布产物**：继续提供 Linux amd64 与 ARM64 的 `.tar.gz` 安装包和 SHA-256 校验文件，不再构建 Windows 安装包。
