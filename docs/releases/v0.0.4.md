## Miniray v0.0.4 更新说明

- **在线升级故障修复**：修复从 v0.0.1 更新时旧安装脚本在执行过程中被覆盖，引发语法错误并中断升级的问题。
- **旧版更新器兼容**：发布包中的管理脚本改用链接布局，保证早期安装器可以完整执行升级流程。
- **Release 版本校验**：更新时解析 GitHub 最新正式 Release 的目标版本，校验下载包内二进制版本与 Release 标签一致。
- **脚本安全替换**：采用临时文件和原子替换方式更新安装、更新与管理脚本。
- **版本信息展示**：更新前输出当前版本，下载时显示目标 Release，完成后输出实际安装版本。
- **Web 面板管理**：新增修改 Web Path 的菜单及命令入口，调整菜单中英文文案。
- **终端菜单布局**：修正分组边框宽度与右侧边框对齐问题。
- **自动化验收**：增加从 v0.0.1 升级并保留数据库和恢复 systemd 服务的测试；正式 Release 发布后执行真实在线升级验收。
- **发布平台**：仅提供 Linux amd64 和 ARM64 的 tar.gz 安装包以及 SHA256SUMS 校验文件。
