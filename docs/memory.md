# 面板内存与功能残留检查

后端只解析 API 响应使用的翻译键，英文与简体中文文案由浏览器按首选语言加载。`internal/web/locale/backend_messages.go` 保存后端键清单；新增 `I18nWeb` 调用时需要同步清单，控制器 AST 检查会校验遗漏。请求使用独立 Localizer，避免并发请求互相覆盖语言。

指标历史使用按需增长、写满后原地覆盖的环形缓冲区。采样精度、聚合规则、历史保留窗口和磁盘格式保持一致：最近 1 小时每 2 秒、48 小时每分钟、7 天每 10 分钟。快照按照时间顺序输出，恢复旧快照后继续采样。

清理范围包括旧通知默认字段与入站 hook 返回值、无效的 IP 空记录文案引用、旧数据库导入允许列表中的通知凭据、闲置赞助代理入口、通知/赞助图片、节点指标定义、无内容测试文件、节点测试参数、PostgreSQL 测试分支和不适用的备份说明。保留升级时清除旧字段/旧协议/旧表所需的数据迁移，以及现有客户端 email 标识、流量、订阅和协议能力。

## 本地测量

基线为 `46e3978`，Linux amd64，Go 1.27.1。同一前端资源、相同初始化数据库，`GOMAXPROCS=2`。面板初始化测量在 Go 测试进程中调用 `StartPanelOnly`，然后执行 `debug.FreeOSMemory`；RSS 来自 `/proc/self/status`。两组各运行三个独立进程，未加载 Xray 内核、没有真实客户端负载。下表是该测试环境的结果，不代表生产服务器的固定占用。

| 测量项 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 13 种语言翻译对象驻留 Go 堆 | 约 15.8 MiB | 约 0.47 MiB |
| 面板初始化测试进程 RSS | 84.3–84.7 MiB | 67.9–68.3 MiB |
| 写满后的单个指标采样平均分配 | 53 B/op | 0 B/op |
| 写满后的单个指标采样耗时 | 47.36 ns/op | 7.604 ns/op |

翻译对象测试：`go test -v ./internal/web/locale -run TestBackendCatalogMemory`。

指标写入基准：`go test ./internal/web/service -run '^$' -bench '^BenchmarkTierBufSteadyState$' -benchmem`。

本地 Go 全量测试中的两个 `/proc/PID/exe` 进程身份测试受执行环境 PID 命名空间与 procfs 不一致影响；基线也复现相同失败。其余 Go 测试、本轮翻译对照/并发请求/环形缓冲区回绕与持久化测试通过。仓库 CI 仍运行完整测试，没有添加跳过项。
