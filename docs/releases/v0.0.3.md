## Miniray v0.0.3 更新说明

- **管理脚本版本展示**：管理菜单首行显示当前安装的 Miniray 版本号，面板及代理核心状态紧随其后。
- **Web 管理界面**：桌面侧边栏与移动端菜单顶部显示当前版本号。
- **完整卸载**：新增终端菜单卸载入口及 `miniray uninstall` 命令，停止并删除 Miniray 服务、程序和运行日志。
- **卸载数据选择**：卸载前询问是否清除数据库，默认保留，支持卸载后复用。
- **重新安装数据库选择**：无现存 Miniray 程序但检测到数据库时，允许复用旧数据库、清除后重新初始化或取消安装。
- **更新版本提示**：执行更新时先打印已安装的版本号。
- **稳定性与验收**：修正 TUIC 流关闭时序引起的测试误判，扩展卸载和重新安装的系统服务验收用例。
- **仓库文档**：更新安装、更新、卸载、数据库处理及发布流程说明。
- **发布产物**：仅提供 Linux amd64 和 ARM64 两种 `.tar.gz` 安装包及 SHA-256 校验文件，不再提供 Windows 构建。
