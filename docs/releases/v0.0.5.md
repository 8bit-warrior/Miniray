## Miniray v0.0.5 更新说明

- **独立 Xray 核心状态**：修复 Web 面板重启或离线后对独立 Xray 进程的运行状态及核心版本识别。
- **核心接管与重启**：Web 面板启动时接管已运行的 Xray 核心，配置未变化时不重复重启；主动重启核心时正确执行强制重启。
- **核心进程管理**：修复独立核心运行时的停止操作，并兼容二进制文件替换后仍在运行的 Linux 进程。
- **面板离线操作**：通过 systemd 或 OpenRC 停止 Web 面板服务，保持独立代理核心运行。
- **核心版本与界面交互**：优化 Xray 版本检测缓存，首页核心状态区域可直接打开版本切换界面。
- **更新版本显示**：执行更新时先显示当前版本、目标 Release 版本，完成后输出实际安装版本。
- **构建与测试修复**：恢复 Xray 启动接口兼容性，修正前端格式及 Go 静态检查问题，并消除 Happ 编辑器、TUIC 测试中的异步时序误判。
- **升级与安装验收**：补充新版更新器的版本显示验证，保留从 v0.0.1 升级、数据库保留、systemd 服务恢复及 Linux 双架构构建验收。
- **发布产物**：仅发布 Linux amd64、Linux ARM64 的 `tar.gz` 包和 `SHA256SUMS` 校验文件。
